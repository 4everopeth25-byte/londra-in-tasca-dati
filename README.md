# Dati della mappa offline di Londra in tasca

Solo dati, nessun codice. Usati dall'app https://4everopeth25-byte.github.io/londra-in-tasca/ (pagina Viaggio, Mappa), che li scarica una volta sola sul telefono.

- `londra-20261121.pmtiles`: mappa vettoriale di Londra centrale (zoom da 0 a 15), estratta dalla build del 21/11/2026 di Protomaps. Dati © OpenStreetMap contributors, licenza ODbL. https://protomaps.com
- `pedonale-20261123.bin.gz`: grafo delle strade percorribili a piedi, calcolato da un estratto OpenStreetMap di Geofabrik (23/11/2026). Dati © OpenStreetMap contributors, licenza ODbL.

Quando la rete della metro e i tempi usati dall'app derivano da dati di Transport for London (TfL Open Data): «Dati forniti da Transport for London». L'app non è un prodotto ufficiale di TfL.
